# Privacy Lamp
An STM32-based smart lighting system controlled through a motion-sensing pen. Developed during the 13th edition of Neapolis Innovation Summer Campus.

## About the Project
The Privacy Lamp uses an ISM330DLC inertial sensor to detect the orientation of a control pen. Commands are transmitted via an HC-05 Bluetooth module to the lamp, where two SG90 servo motors control the rotation on two axes. The user can activate a "follower mode" by pressing a button on the pen, allowing the light to track pen movements.

## Key Features
* Useful for work and study environments.
* Object tracking for videos, presentations, and content creation.
* Private data acquisition in an AI data harvesting world.
* Button-activated follower mode.
* Manual-Automatic interchangeable working mode.

## Hardware Required
* STM32 Nucleo Board (STM32F031K6)
* ISM330DLC Inertial Sensor
* HC-05 Bluetooth Module
* 2x SG90 Servo Motors
